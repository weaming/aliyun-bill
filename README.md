# 阿里云账单查询 TUI

基于阿里云 BssOpenApi 的终端账单查询工具。

## 使用方法

### 设置环境变量

```bash
export ALI_KEY_ID="your-access-key-id"
export ALI_KEY_SECRET="your-access-key-secret"
```

### 运行

```bash
# 交互式查询，默认本月
./aliyun-bill

# 直接查询指定月份
./aliyun-bill 2025-03
```

### 快捷键

| 键 | 操作 |
|---|---|
| `Enter` | 查询 |
| `← →` / `1 2` | 切换标签 (每日消费 / 消费项明细) |
| `↑ ↓` | 逐行翻页 |
| `PgUp PgDn` | 整页翻页 |
| `d` / `f` | 上月 / 下月 (输入模式和数据模式均可) |
| `r` | 刷新当前月份 |
| `q` / `Ctrl+C` / `Esc` | 返回输入 / 退出 |

## 功能

- **每日消费**: 按天+产品维度展示消费明细，显示每日各产品消费和日合计
- **消费项明细**: 按产品聚合展示实例/计费项消费汇总，支持分页浏览
